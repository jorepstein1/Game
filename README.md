# Hearthold

A medieval idle city builder that runs entirely in the browser. No build step and no dependencies: open `index.html` (or serve the folder with any static server).

## How it plays

- **Place buildings on the map.** Position matters: lumber camps want forests, quarries and mines want hills, farms want water and mills, markets want cottages, taverns boost cottages. Bonus badges preview what each plot would give before you build.
- **Balance the village.** Cottages house villagers, working buildings need them, and everyone eats. Run short on food and work slows to half.
- **Upgrade and expand.** Every building can be levelled up (×2 output per level). Raise your Village Hall into a Manor, Keep, Castle and Palace to unlock new buildings and research, and buy more land as you grow.
- **Follow the Decrees.** A chain of goals with rewards that doubles as the tutorial.
- **Catch the merchant.** A caravan wanders onto the map every minute or two: click it for gold, supplies or a ×3 festival.
- **Found a new kingdom.** With a Castle you can abdicate for Crowns, each a permanent +10% to all production.
- **Idle.** The game saves every 10 seconds and credits up to 8 hours of offline progress (24 with research).

## Files

- `index.html` — page shell
- `style.css` — presentation
- `game.js` — data tables, simulation, rendering and saves
